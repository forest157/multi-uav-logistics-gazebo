# 三机五阶段任务集成测试（2026-08-06）

环境：ROS Noetic、Gazebo Classic 11.15.1、PX4 v1.13.2、MAVROS。
场景：scene 0，三架 Iris，初始世界坐标约 (-42,-40)、(-40,-40)、(-38,-40)。

## 结果

- 三机全部进入 OFFBOARD 并解锁。
- 加入同步屏障后，只有三机均达到 armed + OFFBOARD + 高度不低于 4 m 才启动任务时钟。
- 完成线形到 V 形重构、分段平滑绕障巡航、目标区线形重构和下降。
- 巡航阶段抽样位置误差约 0.05–0.35 m，高度保持约 5 m。
- 最终局部目标均为 (85, 85, 0.5)。
- uav0 实际 (85.019, 84.971, 0.503)。
- uav1 实际 (85.040, 85.000, 0.512)。
- uav2 实际 (85.030, 85.018, 0.516)。
- 三机保持 armed + OFFBOARD，未出现端口串线或模式丢失。

## 说明

当前任务轨迹已采用参考项目的自定义三次 B 样条与 TOPPRA 时间参数化：编队安全膨胀 A* 经 LOS 简化后生成安全 B 样条，按缩放场景的 2.0 m/s、1.0 m/s² 约束计算零起终速度轨迹；以 0.1 秒采样写入 YAML，并由 ROS PoseStamped 在运行时发布。
