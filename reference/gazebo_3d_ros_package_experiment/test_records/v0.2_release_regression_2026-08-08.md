## 环境备注

容器内 Python 科学栈存在既有的间歇性对象损坏和原生段错误。生成器以独立进程重试完成七场景验证；rqt 现将已复现特征分类为可重试的 `ENVIRONMENT`，最多自动重试 3 次，仍失败则明确提示运行环境异常。
