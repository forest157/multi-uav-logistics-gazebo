# 响应式净空分析上位机测试记录

## 功能范围

- 场景、起点、终点、高度和队形变化后自动重新分析；
- 参数停止变化700 ms后异步运行OMPL、净空复核和TOPPRA；
- 规划期间不阻塞rqt界面；
- 参数变化立即清除旧结果并禁用仿真启动；
- 只有当前参数签名与已验证任务一致时才允许启动；
- 启动复用已经验证的任务YAML，不重复随机规划；
- 显示最小水平净空、所需包络、安全余量、危险对象、危险位置、上下余量、预计时间、速度和加速度；
- 规划超时、环境异常和不可行任务使用不同状态；
- 对容器间歇性Python科学计算环境异常自动重试一次。

## 验证结果

无界面Qt测试按真实rqt上下文生命周期实例化插件并完成三阶段验证：

1. 场景2默认参数自动分析成功，启动按钮启用；
2. 终点X变化1 m后，旧参数签名立即失效且按钮禁用；
3. 新参数自动重新规划成功，界面净空指标随之更新；
4. 将终点改为与起点重合后，界面显示“起点与终点距离必须至少为3 m”；
5. 不可行参数下启动按钮保持禁用，未复用前一次成功任务。

一次通过记录：

- 首次安全余量约4.51 m；
- 参数变化后安全余量约5.11 m；
- 危险对象识别为plant_room；
- 预计出航约45.2 s；
- 最大速度约1.25 m/s；
- 最大加速度约0.67 m/s²。

OMPL为采样规划器，重复测试的轨迹指标允许小幅变化，但状态转换和启动门控必须保持一致。
