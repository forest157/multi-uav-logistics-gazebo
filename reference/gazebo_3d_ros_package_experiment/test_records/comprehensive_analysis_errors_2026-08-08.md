# 综合分析错误与任务阶段检查记录

## 新增能力

- 统一区分INPUT、FEASIBILITY、PLANNING、DYNAMICS、ENVIRONMENT和INTERNAL；
- 每项错误包含代码、严重程度、是否可重试、中文消息、上下文和建议；
- 起点地面起飞、起点巡航、终点巡航、终点投递、返航降落容量检查；
- 出发、投递、恢复巡航和返航降落四次队形过渡检查；
- 失败时即使没有任务YAML，也输出结构化JSON；
- OMPL超时或暂未找到路径不再错误表述为确定无解；
- TOPPRA延迟导入，使科学计算环境异常能在主流程内分类；
- 上位机显示错误类别、位置、障碍物和中文处理建议；
- 启动前检查任务文件、临时目录、磁盘、ROS master、活动飞行进程和Gazebo端口；
- 活动进程检查忽略容器PID1遗留的僵尸进程。

## 验证

- ROS包构建通过，无警告；
- 15项单元测试通过；
- rqt成功、参数失效、重新分析、输入失败和干净运行时预检通过；
- 七个场景全部通过，每个场景包含9项阶段检查；
- 起点位于(46,46)时正确返回E_START_CAPACITY；
- 起终点重合时正确返回E_DISTANCE和INPUT类别；
- 已验证环境对象异常返回E_ENVIRONMENT；
- 原生科学计算进程段错误由上位机按进程异常和报告缺失处理。

## 当前边界

队形过渡检查当前使用101个插值样本统计原始最小间距，并标记是否需要现有安全距离缩放。障碍物方面采用起终点队形包络的保守容量检查。自动选择变换位置及每架无人机完整过渡轨迹的障碍物连续检查属于下一阶段。
