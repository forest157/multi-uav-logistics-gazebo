# v0.5.6 飞行安全联锁与空域高度保护

日期：2026-09-03

## 目标

- 将现有只读安全报警升级为任务执行层的主动防碰撞联锁。
- 防止没有动态障碍时残留或异常避障命令造成无故上下偏移。
- 保留正常航线高度变化、配送升降和避障解除后的平滑恢复。

## 实现

- 新增基于实际位姿的 `FleetSeparationInterlock`。
- 实际机间距低于 2.7 m 或收到明确的安全 `ERROR` 时，立即锁定全机当前位置并冻结任务时钟。
- 只有机间距恢复到 3.0 m 且稳定 1 秒后才释放，避免阈值附近反复启停。
- 任务状态新增 `SAFETY_HOLD` 和 `safety_interlock` 诊断信息。
- 动态障碍数为零时拒绝应用残留集体偏移；`RECOVERING` 状态仍允许平滑回零。
- 明确区分 ROS `ERROR(2)` 与 `STALE(3)`，防止初始化或解除武装后误触发联锁。

## 验证

- 119 项 Python 测试全部通过。
- catkin 构建成功且无警告。
- 三机无动态障碍完整任务到达 `COMPLETE`，三机全部解除武装。
- 任务期间没有 `SAFETY_HOLD`，最小实际机间距 3.182 m。
- 最小静态障碍净空 2.257 m。
- 全程 `avoidance_offset_z` 最大绝对值为 0，未出现无障碍避障高度漂移。
- 原始记录：`~/.ros/logistics_runs/mission_20260902_135635.csv`。

## 安全语义

安全联锁是最后一道制动保护：它阻止继续逼近，但不会在已经过近时自行生成未经验证的分离机动。若距离无法自然恢复，系统保持悬停并等待人工处理或上层安全规划。
