# v0.5.4 遮挡重关联与轨迹可靠性记录

日期：2026-09-02

## 目标

- 补齐上游检测关联器与下游 1.5 秒遮挡维持窗口，避免短遮挡后更换 ID。
- 将轨迹置信度、观测状态、遮挡时长和 ID 写入任务 CSV。
- 提供离线可靠性汇总命令，支持后续阈值标定。

## 实现

- 关联时使用上一位置和速度预测当前目标位置，不再只比较最后观测位置。
- 新增 `maximum_association_age_s=1.5`；时限内保留关联 ID，超过时限后创建新轨迹。
- 任务 CSV 新增 `track_count`、`observed_track_count`、`mean_track_confidence`、`max_occlusion_s` 和 `track_ids`。
- 新增 `analyze_track_reliability`，汇总观测/遮挡样本、平均置信度、最大遮挡时间和唯一 ID。
- 修复任务记录器关闭时定时器写入已关闭文件的竞态。

## 验证

- 110 项 Python 测试全部通过，catkin 构建无警告。
- 受控遮挡：匀速目标遮挡 1.0 秒后按预测位置重捕获，保持原 ID；超过时限后正确过期。
- ROS 注入 CSV：16 个遮挡样本，平均置信度 0.72、最大遮挡 0.8 秒，唯一 ID 为 `lidar_target_0`。
- scene 0、单鸟、三机物理雷达、collective_offset 完整任务 266.30 秒 COMPLETE，三机均解除武装并进入 AUTO.LAND。
- 完整任务 SAFE 1527、WARNING 81、CRITICAL 26；最大 Z 避障偏移 0，最小机间距 3.221 m。
- 真实任务轨迹统计：206 个有轨迹样本、86 个观测样本、120 个遮挡外推样本、最大遮挡 1.4 秒、平均置信度 0.585。
- 原始任务记录：`~/.ros/logistics_runs/mission_20260902_133005.csv`。

## 指标解释

完整任务中的 11 个唯一 ID 跨越多个相隔较久的进出量程周期，不能直接解释为短遮挡重捕获失败。短遮挡 ID 连续性由受控注入测试单独验证；超过 1.5 秒离场后创建新 ID 是预期行为。
