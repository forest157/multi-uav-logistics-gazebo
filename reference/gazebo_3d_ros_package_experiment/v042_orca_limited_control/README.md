# v0.4.2 ORCA 受限闭环接管

## 版本目标

在 v0.4.1 影子模式基础上，让 3D ORCA 首次真实影响 PX4，同时保留独立安全复核、同步悬停和稳定整队偏移回退。当前唯一主包为 `catkin_ws/src/logistics_gazebo_sim`。

## 完成内容

- 定义 `orca_velocity_v1` 逐机速度命令契约，包含时间戳和有效期；
- 命令安全门检查算法类型、车辆数量与 ID、计划新鲜度和完整安全证明；
- 限制三维速度、爬升率、加速度和指令变化，并进行低通平滑；
- 以名义航线速度作为接管初值，避免首次切换突然刹车；
- ORCA 预测轨迹复核动态障碍、静态建筑、地图边界、高度和机间距；
- WARNING 且计划有效时才允许受限接管；CRITICAL、超时、无解或约束失败同步悬停；
- 上位机支持稳定整队偏移、ORCA 影子模式和 ORCA 受限接管三种选择；
- RViz 显示 ORCA 速度箭头、名义预测轨迹和实际轨迹；
- CSV 记录算法、失败原因和最大 ORCA 命令速度。

## 分级验证

- 65 项 Python 回归测试通过；

- 过期命令立即进入 `dynamic_action=HOLD`，原因是 `ORCA command is stale`。
