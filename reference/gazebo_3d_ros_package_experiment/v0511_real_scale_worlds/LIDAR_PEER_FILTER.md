# 雷达机体回波与切换修复（2026-09-09）

## 诊断依据

诊断订阅器只读记录感知目标、MAVROS 位姿及 Gazebo 模型位置。Gazebo 真值仅用于离线对照，不进入点云过滤或避障输入。

捕获起飞期 lidar_target_2：15.98 s 时目标位置 (-43.2201,-39.9393,3.0845)，接收回调时 uav0 本地位姿的时间已为 16.184 s，世界 XY 约 (-43.426,-40.069)。虚假目标与机体水平位置重合，爬升造成旧回波和最新位姿高度相差超过原 1 m 排除半径。

因此在每帧扫描变换后，使用各机在扫描时刻的历史位姿排除机体回波，然后再合并。半径保持 1 m，没有扩大屏蔽范围。新增反例同时验证机体回波被排除、相距 2 m 的独立目标保留。

实测当前 Gazebo block laser 的消息到达延迟约 0.204 s，聚合计时器又可能等待 0.2 s。上一版 0.3 s 年龄门限会随启动相位持续拒绝正常数据。现在允许最多 0.5 s（0.2+0.2+0.1 s 调度余量），仍保留原扫描时间戳、50 ms 位姿匹配门限和重复帧拒绝。

## 切换行为

仅切换传感器数据源或局部避障模式，不再重跑 OMPL/TOPPRA；这些选择不改变静态全局规划条件。运行期间锁定数据源、局部避障选项及动态障碍开关，退出或启动失败后解锁。选择在下次启动时应用，避免显示的选项与运行配置不一致。

## 验证范围

- 158 项 unittest、catkin 构建通过。
- Qt offscreen 检查：数据源切换前后规划签名一致，运行控件锁定与解锁正常。
- 当前无鸟试验：scene 0，真实雷达，整队避障，三机完整投递返航；中途显式停止并重新启动聚合节点以验证断流恢复。最终结果另附 CSV。
- 受控断流记录：停止前 RUNNING/SAFE/NORMAL；停止后 DYNAMIC_HOLD/STALE/HOLD；恢复后 RUNNING/SAFE/NORMAL，继续原航线。

这些检查不能代替真实动态目标、ORCA 受限接管、其他场景及重复种子的后续验收。全局航线本身的高度变化与避障附加高度必须分别统计。

## 最终结果

无鸟完整任务快照 lidar_peerfix_empty_complete.csv：1747 个采样，最终 COMPLETE，三机均解除武装；所有采样 track_count=0，三轴 avoidance_offset 均为 0。动作计数 NORMAL=1620、SLOW=20、HOLD=107，其中主动断流从 ROS 61.912 s 开始；恢复后正常继续任务。启动与主动断流造成的减速/悬停不等同于误检。

落地后另运行 40 s 移动鸟模型（lidar_positive_bird.yaml），记录 113 个带轨迹的数据帧，其中 39 次 observed=true、4 个不同轨迹 ID。检测结果在目标运动区域附近，证明不是通过关闭检测消除误检；仍存在 ID 分裂，留给轨迹连续性和 ORCA 后续回归。此阶段数据与无鸟任务 CSV 分开保存，不能混作无鸟误检统计。
