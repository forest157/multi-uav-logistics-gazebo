# v0.5.9 电池与能量模型

本版本建立独立于飞控决策的 `energy_v1` 仿真基线，用于为 v0.5.10 的电量感知返航提供可重复输入。本版本只观测、估算和记录，不改变航迹、返航或降落控制。

## 完成内容

- 功率模型覆盖悬停、水平速度、爬升、下降、加速度、转弯和载荷；
- 每架无人机独立配置容量与安全储备，并积分得到已用电量、剩余电量和可用余量；
- 输出任务剩余、返航、等待、降落以及安全落地所需电量；
- 订阅 MAVROS 电池电压和百分比，作为后续 PX4 标定参考；
- `/fleet/energy_state` 发布逐机预测、任务阶段和储备安全状态；
- `mission_recorder` 将关键能量指标写入任务 CSV；
- 任务完成时剩余任务、等待和降落需求归零，避免完成态虚假耗能告警。

默认三机容量为 220、210、200 Wh，安全储备比例为 20%，载荷为 0.5 kg。当前系数标记为 `simulation_baseline_unfitted`；Gazebo/PX4 SITL 返回的电池百分比长期接近 1，不能视为实机标定结果。
