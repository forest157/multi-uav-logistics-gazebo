# v0.4.3 分布式 MPC 影子模式

## 版本目标

在可插拔局部规划接口上增加分布式有限时域轨迹优化器。每架无人机独立求解三维加速度序列，同时考虑名义轨迹、动力学、动态障碍、机间距、队形误差、控制平滑度与能耗代理。本版本只产生影子预测，不接管 PX4。

## 实现与安全边界

- 插件名：`distributed_mpc`，输出契约：`mpc_trajectory_v1`；
- 基于现有 SciPy SLSQP，无需新增 CasADi、CVXPY 或 OSQP 依赖；
- 默认预测 6 步、时间步长 0.4 s，约束速度、水平与竖直加速度及爬升率；
- 各单机独立优化，并共享其他成员映射后的障碍约束以改善队形一致性；
- 输出轨迹再由动态净空、静态场景、边界、高度和全舰队机间距检查器独立复核；
- MPC 无解或轨迹不安全时回退到 3D ORCA；ORCA 仍不安全时同步悬停；
- 上位机、RViz 和 CSV 可显示算法、紫色预测轨迹、可行性和求解耗时。

## 分级验证

### 自动化与不开桨

- 30 组离线场景中 25 组通过独立复核，可行率 83.3%；
- 离线总求解平均 175.68 ms，P95 269.79 ms，P99 339.34 ms，最坏 351.16 ms；
- 不开桨 ROS 数据流输出 3 条轨迹，正常样本约 149.43 ms；
- 极近障碍样本被 MPC 拒绝，随后 ORCA 也拒绝，最终安全语义为悬停；
- 67 项 Python 回归测试通过，catkin 构建成功且无警告。

### Gazebo 完整任务

日期：2026-08-24。配置：scene 0、同高度单鸟、三架 PX4 SITL、MPC shadow、动态避障执行关闭。

- 任务最终进入 `COMPLETE`，三机全部解除武装；
- 记录 93 组 MPC 预测，其中 55 组通过、38 组拒绝，在线可行率 59.1%；
- 总求解平均 165.81 ms，P95 318.23 ms，最坏 370.58 ms；
- 单机最坏求解 159.15 ms，满足当前 2 Hz 影子调用预算；

- 验收 CSV 位于运行环境 `~/.ros/logistics_runs/mission_20260824_182458.csv`，大型运行文件不提交 Git。

## 结论与限制

v0.4.3 验证了接口、计算预算、独立安全拒绝和安全回退链路，但在线可行率尚不足以授权闭环接管。下一版本应通过暖启动、约束改写、预测一致性和参数标定降低局部无解率，再与 ORCA、整队偏移做同场景对照。未经新的闭环验收，不得把 MPC 影子输出直接下发给 PX4。
