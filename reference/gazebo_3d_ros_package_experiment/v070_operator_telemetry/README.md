# v0.7.0 上位机遥测与风险解释视图（开发中，未发布）

0.6.0 已发布且保持稳定；本阶段落地路线图的动态车辆状态表、后端遥测聚合、电量返航建议，以及动态冲突对象与轨迹采样的只读解释视图。不更改飞控控制链路，也不宣称 0.7.0 已完成。

## 实现

- `fleet_operator_telemetry` 以 2 Hz 汇总每架 MAVROS 连接、解锁、模式、局部位姿和电池。三机任务与 1/3/5/8 架规模 launch 都以对应 `vehicle_count` 启动一个汇总节点，rqt 不再为状态表逐机订阅高频位姿。
- 仅在 `/fleet/energy_state` 新鲜时补充模型剩余 Wh；电量优先显示新鲜 MAVROS 电池百分比，否则明确标记为 `MODEL` 估算。无数据时显示 `-`，不会伪装为实测。
- 后端用单调时间判断遥测新鲜度；无效数值、重复车辆 ID、超出 1～8 架范围的 JSON 被拒绝。状态/位姿超过 2.5 s 时显示 `STALE` 且隐藏旧位置；UI 连续 3 s 收不到汇总快照时清空旧行。
- rqt 增加可滚动的车辆表（车辆、状态、模式、高度、电量、模型剩余 Wh、遥测年龄），关闭插件时主动取消 ROS 订阅，避免 Qt 对象销毁后回调。
- rqt 新增只读电量返航建议表，逐机展示预计落地余量、建议返航槽位、建议降落顺序和风险级别。只有策略节点声明 `shadow` 且 `control_applied=false` 的有限数据才进入界面；这不是自动返航控制。槽位未能安全分配时显示“未分配”，不伪造可用槽位。
- 能量输入过期、建议话题中断超过 2.5 s 或消息畸形时立即隐藏旧表并显示保持建议。当前建议节点在收到首帧能量前发布的无穷大年龄，仅作为 `STALE` 处理，不展示旧余量。
- rqt 新增动态冲突预测表，按车辆显示冲突对象、预测最小净空、碰撞倒计时及最近点；汇总行显示最近机对、预测间距、当前局部避障算法及候选建议是否可用。最近点是预测位置，不是实测位置，也不是完整障碍轨迹。
- `/fleet/dynamic_risk` 的失效、畸形、重复车辆、非有限坐标和超过八行报告均失败关闭；话题中断超过 1.5 s 清除旧预测。八机规模模式没有动态风险节点时保持“等待”，不暗示具备八机动态避障。
- 风险节点现在随报告输出世界坐标系下的三点恒速外推轨迹（当前、半程、预测窗口末端），优先保留正在冲突的目标，最多八条并明确显示省略数；被遮挡目标标记“遮挡估计”。rqt 展示轨迹表，并注明这不是实测未来位置。原始障碍源时间戳超过 1 s 时风险报告转为 `STALE`，不再发布旧轨迹。
- rqt 新增最近 50 条规划与安全事件表。最终规划失败及其恢复建议、规划超时、动态风险等级、静态安全诊断、任务安全联锁和紧急降落按状态变化记录；恢复时也记录解除事件。重复的 5 Hz 状态不会刷屏，旧事件仅保存在本次界面会话中，不代替任务报告或飞行日志。

## 验证

- 293 项 Python 回归通过；新增测试覆盖联锁触发/解除、风险与安全诊断去重、规划失败分类和事件上限，并保留轨迹、能量和遥测回归。七包 `catkin build` 全部成功且零警告。
- `roslaunch --nodes` 确认三机与八机入口均只启动一个汇总节点；隔离 ROS master 中八行快照正常，模拟 `uav7` MAVROS 5 Hz 状态/位姿输入后显示 `ARMED`、`OFFBOARD`、18 m，其余仍为过期。
- `QT_QPA_PLATFORM=offscreen` 加载真实 `OperatorPlugin`，验证八行动态渲染及汇总中断 3 s 后清屏。
- `QT_QPA_PLATFORM=offscreen` 加载真实 `OperatorPlugin`，验证能量建议行、槽位显示和建议中断后清屏。
- `QT_QPA_PLATFORM=offscreen` 加载真实 `OperatorPlugin`，验证动态冲突行、算法标签和风险报告中断后清屏。
- `QT_QPA_PLATFORM=offscreen` 加载真实 `OperatorPlugin`，验证三点轨迹、遮挡标记和风险报告中断后轨迹清屏。
- `QT_QPA_PLATFORM=offscreen` 加载真实 `OperatorPlugin`，连续输入 100 帧联锁状态仅留一条触发事件，并验证解除事件及规划恢复建议行。

这些是无桨/无 PX4 的接口和 UI 烟测；尚未对真实八机飞行时的上位机帧率、内存、操作延迟或任务控制按钮做端到端验收。
