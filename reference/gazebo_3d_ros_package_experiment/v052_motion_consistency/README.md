# v0.5.2 运动一致性感知与空域上偏修复

日期：2026-09-01

## 目标

- 用跨帧速度、方向和加速度一致性过滤移动视角下的静态建筑碎片。
- 无有效动态风险时保持零避障偏移，不在空域中自行向上爬升。
- 保留真实单鸟的检测、风险响应与横向规避能力。

## 实现

- 物理雷达候选由三帧邻近确认升级为四帧运动一致性确认。
- 默认运动门控：速度 1.5–12.0 m/s、相邻速度方向余弦不低于 0.7、加速度不高于 5.0 m/s²。
- 集体偏移规划优先选择可行横向候选；仅在横向候选全部不可行时考虑垂直候选。
- 避障恢复到 IDLE 后清除旧 planner failure，避免上位机显示过期故障。
