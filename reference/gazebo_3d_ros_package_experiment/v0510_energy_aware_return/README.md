# v0.5.10 电量感知返航与受限降落

本版本消费 v0.5.9 的能量估计，建立带时效、滞回和安全优先级的返航策略。返航槽位保持影子建议；经过验证的能量优先错峰降落与单机临界备用降落进入受限控制。

## 能力

- 按最终余量分为 `NORMAL`、`LOW`、`CRITICAL`、`STALE`；风险升级立即生效，恢复带 3 Wh 滞回；
- 数据缺失或超过 1.5 秒进入 `STALE`，不沿用陈旧控制；
- LOW 发布返航建议并按距离、垂直代价和能量优先级计算槽位；
- 槽位交换必须通过整段 3.3 m 机间距采样复核，无可行解时不换位；
- 根据能量余量决定降落顺序，受限模式下以 2 秒间隔平滑错峰下降；
- 单架 CRITICAL 时搜索最近备用落点，复核世界边界、静态障碍、水平进近和其他无人机间距后才允许脱队；
- 多架同时 CRITICAL 或找不到安全落点时建议同步 HOLD；
- 实际位姿安全联锁和动态障碍 HOLD 始终覆盖能量控制；
- 上位机和 CSV 显示建议、备用点、控制模式、执行状态和降落顺序。

- 返航策略 ROS 试验覆盖断流、LOW、CRITICAL、多机临界、安全优先和安全槽位；
- 加速不开桨任务验证临界单机备用下降以及 `uav2 → uav1 → uav0` 错峰目标；
- 三机 Gazebo 正常能量完整任务 `COMPLETE`，三机解除武装；
- 完整任务最小机间距 3.210 m，安全 ERROR 与 SAFETY_HOLD 均为 0；
- HOME_DESCENT 最大单采样上浮约 0.011 m，为闭环跟踪噪声，没有目标指令上移；
